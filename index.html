1.1 HTML — Introduction

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on the web. Think of HTML as the skeleton of a webpage — it gives structure, but not style or behavior.

History of HTML

VersionYearKey Feature
HTML 1.01991Basic structure, created by Tim Berners-Lee
HTML 2.01995Forms introduced
HTML 3.21997Tables, applets
HTML 4.011999CSS support, scripting
XHTML2000Strict XML-based HTML
HTML52014Semantic tags, multimedia, APIs

How a Web Page Works

Key Features of HTML

  • Easy to learn — uses simple English-like tags
  • Platform independent — works on all browsers and OS
  • Supports multimedia — images, audio, video
  • Supports hyperlinks — connects pages together
  • Interpreted by browsers — no compilation needed
  • Case-insensitive (though lowercase is best practice)
  • Works with CSS and JavaScript for complete web pages
⭐ Exam Focus
HTML is not a programming language — it is a markup language. It cannot perform logic, loops, or conditions. Always remember this distinction!

Basic HTML Document Structure

HTML<!-- Every HTML document follows this structure -->
<!DOCTYPE html>                  <!-- Declares HTML5 -->
<html lang="en">                  <!-- Root element -->
  <head>                          <!-- Metadata section -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
  </head>
  <body>                          <!-- Visible content here -->
    <h1>Hello, World!</h1>
    <p>This is my first webpage.</p>
  </body>
</html>
📖 📖 Definition
HyperText means text that contains links to other texts (hyperlinks). Markup Language means it uses tags to "mark up" or annotate text with meaning and structure.
💡 💡 Pro Tip
Always include <!DOCTYPE html> at the very first line. It tells the browser to use the latest HTML5 standards. Without it, browsers may switch to "quirks mode" which can cause unexpected layout issues.

1.2 HTML Tags & Elements

HTML uses tags to mark up content. A tag is enclosed in angle brackets < >. Most elements have an opening tag and a closing tag.

Element
Complete unit = opening tag + content + closing tag. E.g., <p>Hello</p>
Tag
The label itself. E.g., <p> or </p>
Attribute
Extra info inside the opening tag. E.g., href="..."
Value
The data of the attribute. E.g., "https://google.com"
Void/Self-closing
Tags with no content or closing tag. E.g., <br>, <img>, <input>

1.4 CSS — Types & Properties

CSS stands for Cascading Style Sheets. It controls how HTML elements look — their color, size, font, spacing, layout, and animation. If HTML is the skeleton, CSS is the skin and clothing.

Types of CSS

TypeWhere WrittenSyntaxPriority
Inline CSS Inside an HTML tag's style attribute <p style="color:red;"> Highest (overrides all)
Internal CSS Inside <style> in <head> <style> p { color: red; } </style> Medium
External CSS A separate .css file linked via <link> <link rel="stylesheet" href="style.css"> Lowest (but best practice!)

Example of All Three Types

HTML<!-- 1. External CSS (in <head>) -->
<link rel="stylesheet" href="styles.css">

<!-- 2. Internal CSS (in <head>) -->
<style>
  h1 {
    color: blue;
    font-size: 32px;
  }
</style>

<!-- 3. Inline CSS -->
<p style="color: red; font-weight: bold;">
  This text is red and bold.
</p>

CSS Selectors

CSS/* Element selector — applies to all <p> tags */
p { color: black; }

/* Class selector — applies to class="highlight" */
.highlight { background: yellow; }

/* ID selector — applies to id="title" (unique!) */
#title { font-size: 36px; }

/* Descendant — <p> inside .container */
.container p { margin: 10px; }

/* Pseudo-class — style on hover */
a:hover { color: red; text-decoration: underline; }

/* Pseudo-element — style first line of <p> */
p::first-line { font-weight: bold; }

/* Universal selector — applies to everything */
* { box-sizing: border-box; }

The CSS Box Model

Every HTML element is treated as a box. The box model defines how space is calculated.

CSS.box {

  padding: 20px;         /* Space inside border */
  border: 2px solid black; /* Border line */
  margin: 15px;          /* Space outside border */

  /* box-sizing: border-box makes width include padding+border */
  box-sizing: border-box;
}

1.6 JavaScript — Features & Overview

JavaScript (JS) is a lightweight, interpreted, object-oriented programming language primarily used to make web pages interactive. It runs directly in the browser — no server needed.

Key Features of JavaScript

Interpreted
Runs line by line in the browser — no compilation step needed.
Dynamic Typing
Variables can hold any type and change type at runtime.
Event-Driven
Responds to user actions — clicks, keyboard, mouse events.
Object-Oriented
Supports objects, classes, inheritance, and encapsulation.
Functional
Functions are first-class — can be stored, passed, returned.
Asynchronous
Handles async tasks (API calls) without blocking the page.
Cross-Platform
Works in all modern browsers — Chrome, Firefox, Safari, Edge.
Versatile
Frontend (browser), Backend (Node.js), Mobile (React Native).

⭐ Exam Focus — == vs ===
Always use === (strict equality) in JavaScript. == does type coercion which can cause unexpected results. Example: 0 == false is true, but 0 === false is false.

}

1.13 Figma Tool

Figma is a cloud-based, collaborative UI/UX design tool used to create wireframes, mockups, prototypes, and design systems. It runs entirely in the browser — no installation needed (though a desktop app is available).

Installation / Getting Started

  1. Go to figma.com and click "Get started for free"
  2. Create a free account (or sign in with Google)
  3. Click "New File" to open the Figma editor in your browser
  4. Optionally download the Desktop App from figma.com/downloads

Figma Interface Overview

Figma Layers

Every element in Figma is a layer. Layers can be grouped, nested inside frames, and reordered. The Layers panel (left side) shows the layer hierarchy — similar to HTML's DOM tree.

UX Principles in Figma

Consistency
Use the same components, colors, and fonts throughout. Use Figma's design system / shared styles.
Visual Hierarchy
Make important things bigger and bolder. Use contrast to guide attention.
Whitespace
Give elements room to breathe. Avoid cramped layouts. Use Figma's Auto Layout.
Accessibility
Ensure color contrast ratio meets WCAG standards. Use Figma's A11y plugins.
Feedback
Users need to know what happened after their action. Show states: hover, active, loading.
Simplicity
Remove unnecessary elements. "Perfection is achieved not when there's nothing to add, but when nothing to remove."

Colors in Figma

  • Fill — background color of a shape or frame
  • Stroke — border/outline color
  • Color Styles — save colors as named styles (like CSS variables)
  • Opacity — 0% to 100% transparency
  • Gradients — Linear, Radial, Angular, Diamond gradients
  • Always define a color palette first (Primary, Secondary, Neutral, Semantic)

Typography in Figma

  • Figma integrates with Google Fonts (free) and supports custom fonts
  • Define Text Styles: H1, H2, Body, Caption, Button — consistent typography
  • Key properties: Font Family, Size, Weight, Line Height, Letter Spacing
  • Type Scale: Use a ratio (1.25x, 1.333x) to create harmonious font sizes

Prototyping in Figma

Figma allows linking frames together to simulate user interactions — without writing code.

  1. Select a button or element
  2. Switch to the Prototype tab (right panel)
  3. Drag the blue arrow to the destination frame
  4. Choose interaction type: On Click, On Hover, On Drag
  5. Choose animation: Instant, Dissolve, Smart Animate, Slide
  6. Click Present (▶) to preview the prototype

  • HTML5 introduced semantic tags like <header>, <nav>, <section>, <article>, <footer>.
  • CSS controls presentation — colors, fonts, layout. Three types: Inline, Internal, External.
  • The CSS Box Model: Content → Padding → Border → Margin.
  • JavaScript adds behavior — variables, loops, functions, DOM manipulation, events, animations.
  • Use === (strict) not == (loose) for comparisons in JS.
  • jQuery simplifies JavaScript with shorter selectors and built-in animations/AJAX.
  • Full Stack = Frontend + Backend + Database + DevOps. MERN is most popular today.
  • Git tracks file versions — key commands: init, add, commit, push, pull, branch, merge.
  • Figma is a browser-based UI/UX design tool — use it for wireframes, mockups, and prototypes.

Unit 1 — Viva Questions & Answers

  1. What is HTML? Is it a programming language? HTML stands for HyperText Markup Language. It is NOT a programming language — it is a markup language used to structure web content. It cannot perform logic, loops, or conditions.
  2. What does DOCTYPE declaration do? <!DOCTYPE html> tells the browser to use HTML5 standards mode. Without it, browsers use "quirks mode" which may cause layout inconsistencies.
  3. What is the difference between <div> and <span>? <div> is a block-level element that takes full width and starts on a new line. <span> is an inline element that only takes as much width as needed and doesn't break onto a new line.
  4. What are the three types of CSS? Inline CSS (inside style attribute), Internal CSS (inside <style> tag in <head>), and External CSS (separate .css file linked via <link> tag). External CSS is the best practice.
  5. Explain the CSS Box Model. Every element is a box with four areas from inside to outside: Content (actual text/image), Padding (space inside border), Border (line around the element), and Margin (space outside the border).
  6. What is the difference between == and === in JavaScript? == is loose equality — it compares only values after type coercion (e.g., 5 == "5" is true). === is strict equality — it compares both value AND type (e.g., 5 === "5" is false). Always prefer ===.
  7. What is the DOM? DOM stands for Document Object Model. It is a tree-like representation of an HTML document that JavaScript can access and manipulate. Every HTML element is a node in the DOM tree.
  8. What is jQuery and why is it used? jQuery is a JavaScript library that simplifies HTML DOM manipulation, event handling, animation, and AJAX. Its motto is "Write Less, Do More." It's used because it reduces code length and handles cross-browser compatibility.
  9. What is the difference between var, let, and const? var is function-scoped and can be redeclared (older, avoid). let is block-scoped and can be reassigned (modern). const is block-scoped and CANNOT be reassigned after declaration.
  10. What is Git and why do we use it? Git is a distributed version control system that tracks changes in files over time. We use it to: save project history, collaborate with teams, revert to earlier versions, and work on features in separate branches.
  11. What is the difference between git pull and git fetch? git fetch downloads changes from remote but doesn't integrate them into your working files. git pull = git fetch + git merge — it downloads AND integrates changes automatically.
  12. What is Figma used for? Figma is a cloud-based UI/UX design tool used for creating wireframes, mockups, prototypes, and design systems. It supports real-time collaboration, runs in the browser, and is used to design interfaces before coding them.
  13. What are semantic HTML tags? Give examples. Semantic tags have meaningful names that describe their purpose. Examples: <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>. They improve accessibility and SEO compared to using <div> for everything.
  14. What is requestAnimationFrame in JavaScript? requestAnimationFrame is a browser API for performing smooth animations. Unlike setInterval, it syncs with the browser's refresh rate (usually 60fps), resulting in smoother animations and better performance.
  15. What is Full Stack Development? Full Stack Development means working on all layers of a web application — Frontend (what users see: HTML/CSS/JS/React), Backend (server logic: Node.js/Python), and Database (MySQL/MongoDB). A full stack developer can build a complete application end-to-end.

2.1 Bootstrap — Introduction

Bootstrap is the world's most popular open-source CSS framework for building responsive, mobile-first websites. It provides a ready-made collection of CSS classes and JavaScript components so you don't have to write everything from scratch.

Responsive

Consistent
Cross-browser compatible — looks the same on Chrome, Firefox, Safari.
Customizable
Override styles with your own CSS or via Sass variable overrides.

Unit 2 — Viva Questions & Answers

  1. What is Bootstrap and who created it? Bootstrap is an open-source CSS framework for building responsive, mobile-first websites. Created by Twitter engineers Mark Otto and Jacob Thornton in 2011. Current stable version is Bootstrap 5.
  2. What is the Bootstrap grid system based on? Bootstrap's grid is based on Flexbox. It uses a 12-column layout with the pattern: container → row → col-*. Column numbers in a row must add up to 12.
  3. List all Bootstrap 5 breakpoints with their pixel values. xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), xxl (≥1400px).
  4. What is the difference between .container and .container-fluid? .container has a fixed max-width at each breakpoint, centering content with padding. .container-fluid is always 100% of the viewport width — used for full-width sections.
  5. What does col-md-4 offset-md-4 do? col-md-4 creates a 33.33% wide column on medium+ screens. offset-md-4 pushes it 4 columns to the right, effectively centering it (4 offset + 4 col = 4 remaining = 12 total).
  6. What is Bootstrap's Reboot? Reboot is Bootstrap's CSS normalization layer. It creates a consistent baseline across browsers by resetting margin, box-sizing to border-box, and making images responsive by default.
  7. How do you make a Bootstrap table scroll on small screens? Wrap the table in <div class="table-responsive">. This adds horizontal scroll on small screens when the table is too wide.
  8. Explain Bootstrap form validation flow. 1) Add class="needs-validation" and novalidate to form. 2) On submit, JS checks form.checkValidity(). 3) If invalid, preventDefault() stops submission. 4) JS adds .was-validated to form. 5) Bootstrap then shows .valid-feedback (green) or .invalid-feedback (red) per field.
  9. What is the difference between a Tooltip and a Popover? Tooltip: triggered on hover, shows only a short text message (from title attribute), small size. Popover: triggered on click, shows both a title and content body, larger. Both need JS initialization: new bootstrap.Tooltip/Popover(element).
  10. What is the structure of a Bootstrap Modal? .modal → .modal-dialog → .modal-content → .modal-header (title + close button) + .modal-body (main content) + .modal-footer (action buttons). Open with data-bs-toggle="modal" data-bs-target="#id" on a button.
  11. What is the difference between Collapse and Accordion? Collapse toggles individual elements independently. Accordion uses multiple collapses where only one stays open at a time — achieved by setting data-bs-parent to the accordion container ID on each collapse panel.
  12. What is Sass and how does it differ from CSS? Sass (Syntactically Awesome Stylesheets) is a CSS preprocessor that adds $variables, nesting, @mixin (reusable blocks), @extend (inheritance), and arithmetic. Browsers cannot read .scss files — they must be compiled to CSS first.
  13. How do you customize Bootstrap's colors using Sass? Override Bootstrap's Sass variables BEFORE the @import: $primary: #yourColor; @import "bootstrap/scss/bootstrap"; This changes all components that use the primary color automatically throughout the framework.
  14. What are Bootstrap utility classes? Single-purpose CSS helper classes that apply one specific style. Examples: mt-3 (margin-top), d-flex (display:flex), text-center, bg-primary. They let you style elements directly in HTML without writing custom CSS.
  15. Why does Bootstrap 5 have higher z-index for Tooltip than Modal? Tooltips (z-index 1080) need to appear above Modals (z-index 1055) because tooltips may be triggered inside modal dialogs and must visually overlay them. The z-index hierarchy ensures correct stacking of all Bootstrap overlapping components.

3.7 Redux Thunk & Fetch API

Redux Thunk is middleware that allows action creators to return functions instead of plain action objects. This enables asynchronous logic (like API calls) inside Redux.

JavaScript// store/postsSlice.js — Async thunk with createAsyncThunk
import { createSlice, createAsyncThunk } from '@reduxjs/toolkit';

// 1. Create the async thunk
export const fetchPosts = createAsyncThunk(
  'posts/fetchAll',           // action type prefix
  async () => {
    const response = await fetch('https://jsonplaceholder.typicode.com/posts');
    const data = await response.json();
    return data;  // becomes action.payload
  }
);

// 2. Handle the three states: pending, fulfilled, rejected
const postsSlice = createSlice({
  name: 'posts',
  initialState: {
    items: [],
    loading: false,
    error: null,
  },
  reducers: {},
  extraReducers: (builder) => {
    builder
      .addCase(fetchPosts.pending, (state) => {
        state.loading = true;
        state.error = null;
      })
      .addCase(fetchPosts.fulfilled, (state, action) => {
        state.loading = false;
        state.items = action.payload;
      })
      .addCase(fetchPosts.rejected, (state, action) => {
        state.loading = false;
        state.error = action.error.message;
      });
  },
});

export default postsSlice.reducer;
JSX// PostsList.jsx — Component using the async thunk

Redux reducers are synchronous and pure. But fetching data from an API is asynchronous. Thunk lets you write async action creators — they can make API calls and dispatch actions when the data arrives. Redux Toolkit includes thunk by default.

Unit 3 — Viva Questions & Answers

  1. What is React and who maintains it? React is an open-source JavaScript library for building user interfaces using a component-based architecture. It's maintained by Meta (Facebook) and the open-source community. It uses a Virtual DOM for efficient updates.
  2. What is JSX? Why can't browsers read it directly? JSX (JavaScript XML) is syntax that looks like HTML inside JavaScript. Browsers can only read standard JavaScript, so JSX must be compiled (by Babel or Vite) into React.createElement() calls before the browser can execute it.
  3. What is the difference between Props and State? Props are data passed FROM a parent component TO a child — they are read-only and cannot be changed by the child. State is data that BELONGS to a component — it can change over time and changing it triggers a re-render.
  4. What is the Virtual DOM? The Virtual DOM is a lightweight JavaScript copy of the real DOM kept in memory by React. When state changes, React updates the Virtual DOM first, compares it to the previous version (diffing), and then only updates the parts of the real DOM that actually changed — making updates very fast.
  5. What is useState? Give an example. useState is a React hook for managing local component state. Example: const [count, setCount] = useState(0); — count holds the current value (0 initially), setCount is the function to update it. Calling setCount(1) sets count to 1 and re-renders the component.
  6. What is useEffect and what does the dependency array do? useEffect runs side effects (API calls, subscriptions, DOM manipulation) after a component renders. The dependency array controls when it runs: no array = every render, [] = once on mount, [dep] = whenever dep changes.
  7. Why is the key prop required when rendering lists? React uses key props to identify which items in a list changed, were added, or removed. Without keys, React re-renders all list items on any change. Keys must be unique among siblings and should be stable IDs — not array indices (which change when items are reordered).
  8. What is Redux and why is it used? Redux is a predictable state management library. It creates a single global store for all app state, solving the "prop drilling" problem (passing data through many levels). It enforces unidirectional data flow: Action → Dispatch → Reducer → Store → View.
  9. What are Redux Reducers? What rules must they follow? Reducers are pure functions that take (currentState, action) and return new state. Rules: (1) Pure — same input always gives same output. (2) No side effects — no API calls or random values. (3) Never mutate state directly — return a new state object. Redux Toolkit uses Immer to allow apparent mutation safely.
  10. What is Redux Thunk? Redux Thunk is middleware allowing action creators to return functions instead of plain action objects. This enables asynchronous operations (like API calls) inside Redux. createAsyncThunk from Redux Toolkit simplifies this with automatic pending/fulfilled/rejected action types.
  11. What are the HTTP methods in REST API and what does each do? GET (read/fetch data), POST (create new resource), PUT (replace entire resource), PATCH (partial update), DELETE (remove resource). These map to CRUD: Create=POST, Read=GET, Update=PUT/PATCH, Delete=DELETE.
  12. What is the difference between controlled and uncontrolled components in React? Controlled components have their form values stored in React state, managed via useState and onChange handlers. Uncontrolled components store values in the DOM, accessed via useRef. Controlled is the React-recommended approach for form handling as it gives full control over input values.
  13. What is useSelector and useDispatch in Redux? useSelector is a hook to read (select) data from the Redux store. It takes a selector function: useSelector(state => state.counter.value). useDispatch is a hook to get the dispatch function for sending actions to the store: dispatch(increment()).
  14. What is the difference between React Testing Library and Jest? Jest is the testing framework — it provides the test() and expect() functions, mocking, and the test runner. React Testing Library (RTL) is a set of utilities for rendering React components in tests and finding elements (getByText, getByRole). They are used together — Jest runs the tests, RTL provides React-specific helpers.
  15. How do you build and deploy a React app? Run npm run build — this creates an optimized /dist folder with minified, bundled JavaScript and CSS. This folder can be deployed to Vercel (connect GitHub repo, auto-deploys on push), Netlify (drag-and-drop /dist), or GitHub Pages (npm run deploy with gh-pages package).

Step 2 — Movies Slice (Redux + Thunk)

JavaScript// store/moviesSlice.js
import { createSlice, createAsyncThunk } from '@reduxjs/toolkit';
import axios from 'axios';

const API_KEY = import.meta.env.VITE_TMDB_API_KEY;
const BASE    = import.meta.env.VITE_BASE_URL;

export const fetchMoviesByCategory = createAsyncThunk(
  'movies/fetchByCategory',
  async (category) => {
    const { data } = await axios.get(
      `${BASE}/movie/${category}?api_key=${API_KEY}&language=en-US&page=1`
    );
    return { category, movies: data.results };
  }
);

const moviesSlice = createSlice({
  name: 'movies',
  initialState: {
    trending: [], popular: [], topRated: [], upcoming: [],
    loading: false, error: null,
  },
  reducers: {},
  extraReducers: (builder) => {
    builder
      .addCase(fetchMoviesByCategory.pending,   s => { s.loading = true; })
      .addCase(fetchMoviesByCategory.fulfilled, (s, a) => {
        s.loading = false;
        s[a.payload.category] = a.payload.movies;
      })
      .addCase(fetchMoviesByCategory.rejected,  (s, a) => {
        s.loading = false; s.error = a.error.message;
      });
  },
});

export default moviesSlice.reducer;
